Запусти агента `planner` через Agent tool (subagent_type: "planner") на один проход.

Задача уже определена самим запуском Symphony (идентификатор, заголовок,
описание, статус, URL, лейблы Linear-тикета уже есть в контексте этого
сообщения выше) — передай их агенту `planner` как есть. Все данные берём
только из самого тикета; не ищи задачу в Sentry, не читай и не пиши никакие
локальные файлы для координации.

Агент проверяет задачу по текущему коду и, если `CONFIRMED`, записывает план
прямо в Linear-комментарий `## Agent Workpad` этого тикета через
`linear_graphql`. Он не пишет код, не трогает git и не реализует фикс.

Дождись завершения и кратко перескажи: вердикт (`CONFIRMED` / `ALREADY_FIXED` /
`REJECTED` / `NEEDS_HUMAN_DECISION`).

Вход (идентификатор Linear-тикета):
$ARGUMENTS
